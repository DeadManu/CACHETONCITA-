# Mis recuerdos más bonitos

Esta es una galería vertical de recuerdos con un fondo estrellado y un cielo en movimiento.  
Incluye quince fotografías y se ha diseñado para abrirse fácilmente desde dispositivos móviles o navegadores de escritorio.

## Estructura del proyecto

- **index.html**: archivo principal que carga la galería y el cielo estrellado.
- **css/styles.css**: define estilos para el fondo, las estrellas y la presentación de las imágenes.
- **js/script.js**: genera dinámicamente las secciones de la galería y el cielo animado.
- **assets/fotos/**: contiene las quince imágenes utilizadas en la galería.
- **package.json** y **vercel.json**: archivos de configuración para plataformas de despliegue como Vercel.

## Despliegue

1. Copia todos los archivos y carpetas a tu repositorio de GitHub.
2. Asegúrate de que el proyecto está en la raíz del repositorio para que Vercel lo detecte como un sitio estático.
3. Importa el repositorio en Vercel; la configuración predeterminada debería funcionar correctamente.  
4. Una vez desplegado, obtendrás una URL `*.vercel.app` para compartir tu carta.
